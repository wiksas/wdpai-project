# Dokumentacja wymagań KOMOREBI

| Plik | Zawartość |
| --- | --- |
| [user-stories.md](user-stories.md) | Historyjki użytkownika z kryteriami akceptacji, pogrupowane według obszarów aplikacji |
| [specification.md](specification.md) | Specyfikacja: aktorzy, wymagania funkcjonalne i niefunkcjonalne, model danych, trasy HTTP, ograniczenia |
| [use-cases.md](use-cases.md) | Przypadki użycia: przebieg główny, scenariusze alternatywne i wyjątki |

Dokumenty opisują stan aplikacji na gałęzi `main`. Identyfikatory łączą je ze sobą: historyjka `US-xx` wskazuje wymaganie `FR-xx`, a przypadek użycia `UC-xx` realizuje jedną lub kilka historyjek. Szczegóły techniczne (architektura, konwencje kodu) są w `AGENTS.md`, uruchomienie w `README.md`, kierunek wizualny w `DESIGN.md`.
